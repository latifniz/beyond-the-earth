## Voices (recorded lines in assets/audio/voice/)
Generated offline with **Piper** (open-source neural text-to-speech, MIT licence, https://github.com/rhasspy/piper) using the voice models from https://huggingface.co/rhasspy/piper-voices :
- Teacher: `en_GB-jenny_dioco-medium` (British female voice)
- Student: `en_US-hfc_female-medium` (American female voice)
Please re-check each voice model's licence on its model card before publishing.

## Sound
The music and sound effects are generated by the browser (Web Audio API) from `js/core/audio.js`. The spoken lines are the recorded voice files described in the Voices section above.

## Code
Written for this project in plain HTML, CSS and JavaScript. The only library used is Three.js (see the 3D graphics section above) for the realistic space scenes.
